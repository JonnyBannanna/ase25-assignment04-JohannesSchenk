The prototype will focus on

- **FR:** As a customer, I want to browse meals offered by the catering service so that I can choose a suitable meal.
- **NFR:** As a customer, I want the platform to be intuitive to use so that I can navigate through the browsing and ordering process with ease.

Browsing available meals is one of the core functionalities of the service and therefore a reasonable scope for the first prototype. 
Since the browsing process is also the main entry point for the user, the interface should be clear and easy to understand, as mentioned in the NFR.
The FR and NFR are closely related because the effectiveness of the browsing feature directly depends on how intuitive the interface is.
