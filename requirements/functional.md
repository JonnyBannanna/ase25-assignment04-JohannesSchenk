# Functional Requirements (FR)

1. As a customer, I want to browse meals offered by the catering service so that I can choose a suitable meal.
2. As a customer, I want to search meals by name, ingredient or category so that I can find meals that match my preferences more quickly.
3. As a customer, I want to view the list of ingredients required for a meal so that I can ensure it fits my dietary requirements (e.g. allergies).
4. As a customer, I want to order the ingredients for a selected meal so that I can prepare the meal.
5. As a customer, I want to schedule the ingredient deliveries (same-day or next-day) so that the ingredients arrive when I need them.
6. As a customer, I want to track the status of my order so that I can plan according to the expected delivery time.
