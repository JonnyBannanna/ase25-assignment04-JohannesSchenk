# Non-Functional Requirements (NFR)

1. As a customer, I want the platform to be responsive and lightweight so that I can use it without interruptions or long waiting times.
2. As a customer, I want the platform to be intuitive to use so that I can navigate through the browsing and ordering process with ease.
3. As a developer, I want the platform to be easy to maintain and extend so that new meal types or dietary rules can be added without much effort.
4. As a customer, I want the system to not lose my order details if the system crashes so that I can continue my order at a later point.
